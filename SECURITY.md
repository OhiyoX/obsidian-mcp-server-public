# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through the repository host's security
advisory feature, or contact the maintainers through the private channel they
publish. Do not open a public issue for a vulnerability that could expose
credentials, vault contents, or a deployment. Do not include real secrets in any
report; describe the class of data and use synthetic values.

## Scope

This repository is a source distribution. Deployment-specific configuration and
production credentials are not part of it.
