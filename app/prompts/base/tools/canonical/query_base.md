Query common safe Base filters and sorting in Docker. Supports and/or/not, comparisons, contains, startsWith, endsWith, file.inFolder, file.hasTag, and file.hasLink. Also evaluates the safe file.asLink(if(property, property, file.name)) formula subset into structured link cells; unsupported formulas fail closed. `format` selects the response rendering: json (default, unchanged DTO), csv, tsv, md, or paths. When the selected view declares `groupBy` / `summaries`, the DTO additionally carries `groups` (group key, keyType, count, rowPaths, per-group summaries) and — when declared — the view-wide `summaries`; both keys are absent when nothing is declared, and the csv/tsv/md/paths text never expresses grouping (read `structuredContent` for it). Three optional ad-hoc inputs narrow or reorder one call without writing the .base file: `filters` (the .base filter-group dialect: and/or/not groups, {key,op,value} leaves from the frozen operator list, or an advanced expression string) is AND-combined with the base and view filters; `sort` ([{property, direction}], direction asc|desc, default asc) REPLACES the view sort; `search` (case-insensitive substring over the view columns, like the Web `q`) is AND-combined with the filters. Pipeline order is filters -> search -> sort -> limit -> grouping -> summaries; `limit` keeps its historical meaning (an explicit row ceiling that overrides the view limit).
