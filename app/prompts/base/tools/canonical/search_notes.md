Query syntax: spaces between clauses are an implicit AND; an uppercase OR starts an alternative group; -term or -field:value negates; quoted text stays an exact phrase; operators path:, file:, tag:, content:, line:, section: and [property] filter notes. semantic omitted uses exact-first auto (the exact pass runs first; hybrid retrieval is attempted only when it matches zero records and the query has a positive text term); semantic=false is strict exact/lexical only; semantic=true always runs hybrid retrieval for positive text; regex mode is incompatible with semantic=true.
