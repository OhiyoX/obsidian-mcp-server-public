Create an HTTP upload handle so the file bytes travel from the client to the server without passing through the model, MCP JSON or base64. Send bytes to relativePath with the same credential. Either PUT the exact bytes in one request with the exact Content-Length, or resumable: PATCH consecutive byte ranges with Upload-Offset set to the bytes already stored (single writer, contiguous only; a mismatched offset returns 409 with the authoritative Upload-Offset). An interrupted upload can be resumed from its stored offset instead of restarting; expect a transient 409 UPLOAD_IN_PROGRESS right after a disconnect and retry after a short backoff.
