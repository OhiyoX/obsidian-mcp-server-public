# Field Study

Track how people actually navigate a large note collection.

## Questions

- Do people search before they browse?
- How often does the graph answer a real question?
- Which links decay fastest?

## Method

1. Seed five realistic tasks.
2. Observe navigation without prompting.
3. Record the first successful path.
4. Compare against the lexical-only baseline.
