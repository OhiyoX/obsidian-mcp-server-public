# Demo release checklist

- [ ] Health endpoint returns `ok: true`
- [ ] Search returns at least one expected note
- [ ] Graph health shows only intentional unresolved links
- [ ] Revision token round-trips on a write
- [ ] Trash restore works for a deleted note
- [ ] Publish link is created and can be revoked
- [ ] Desktop screenshot at 1440x900
- [ ] Mobile screenshot at 390x844
- [ ] No private path, host or credential in any frame
